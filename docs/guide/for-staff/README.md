# For clinic staff

Daily workflows for front desk and clinical staff using PocoClinic on clinic workstations.

## In the EMR

| Task | Where |
|------|--------|
| **Sign in** | `/login` — scan badge, enter PIN |
| **Find patients** | Sidebar → Patients |
| **Patient chart** | Click patient name |
| **Change PIN** | Sidebar → Change PIN |
| **Help** | Sidebar → Help & Support, or **?** in header |

## Quick start (first day)

1. Receive printed badge from administrator
2. Sign in at `/login` — scan badge, enter PIN from admin
3. Set **private PIN** when prompted
4. Open **Patients** → search or register
5. Open a chart → add notes, upload documents, log exercises, fill forms as trained

**Printed system help:** [Staff how-to (ops binder Section C)](../../ops/binder/C2-staff-how-to.md)

## Privacy reminders

- Sign out or lock workstation when leaving the desk
- Do not share PIN or badge
- Sessions end after 15 minutes of inactivity
