# Patient care workflows

## Find a patient

1. **Patients** in the sidebar
2. Type a name in search
3. Click the row to open the chart

## Register a new patient

1. **Patients → New patient**
2. Required: first name, last name, date of birth, gender
3. Add contact info and address as needed
4. **Save**

## Patient chart

The chart shows:

- **Demographics** — edit via Edit Patient
- **Clinical notes** — timestamped timeline; authors can edit or delete their own notes; administrators can delete any note; all changes are audit-logged
- **Documents** — upload PDF, PNG, JPEG, GIF, or text (max 10 MB); encrypted in the clinic database
- **Exercise log** — PT plans and session entries (sets/reps/resistance/difficulty)
- **Forms** — templates your administrator configured

On wider displays, notes and documents appear side by side.

## Clinical notes

1. Scroll to **Clinical notes**
2. Type note → **Add note**
3. Edit or delete your own notes with the pencil/trash icons; administrators can delete any note
4. Deleted notes stay in the audit log even when removed from the chart

## Documents

1. Scroll to **Documents**
2. **Upload file** — encrypted and stored in the clinic database (backed up with USB backups)
3. Download or remove as policy allows

## Exercise log

1. Scroll to **Exercise log**
2. Create or select a plan
3. Add session entries as trained
4. Changes are audit-logged and included in database backups

## Forms

1. Scroll to **Forms**
2. Choose template → complete fields → save
3. Submission stays on the patient chart

## Delete a patient

**Delete** on the chart — permanent. Use only per clinic policy; action is audit-logged.
