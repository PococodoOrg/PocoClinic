# For clinic administrators

Administrators set up the server, manage staff and badges, protect data with USB backups, and keep the system healthy.

## In the EMR

| Task | Where |
|------|--------|
| **Setup checklist & all admin tasks** | Admin dashboard → **Administrator guide** |
| **System health & backups** | Admin dashboard |
| **Staff & badges** | Sidebar → Staff |
| **Forms & reports** | Sidebar → Forms |
| **Audit log** | Sidebar → Audit log |
| **Searchable help** | Sidebar → Help & Support (admin articles) |
