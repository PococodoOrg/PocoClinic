# Monthly testing checklist

Use on the **first weekday of each month** — print, complete, and file in the ops binder alongside the [security audit checklist](./security-audit-checklist.md).

**Clinic:** __________________ **Month:** __________________ **Initials:** ____

## Automated checks (admin dashboard)

- [ ] **Overview → HIPAA compliance checklist** — run checklist; resolve any Fail items before end of day
- [ ] **Backup & maintenance → System health check** — run check; document any Warning items
- [ ] **Overview → Security overview** — confirm zero default PIN accounts
- [ ] **Reports → Clinic activity** — review failed sign-ins for the last 30 days

## Backup & recovery

- [ ] Create a fresh backup if none in the last 24 hours
- [ ] **Verify** the latest backup file (integrity check on admin dashboard)
- [ ] Confirm USB rotation labels are current (Backup label panel)
- [ ] If last restore drill was **> 90 days ago**, schedule one this month

## Audit & access

- [ ] Export audit log CSV (30 days) and store in secure admin folder or binder appendix
- [ ] Review locked accounts and unusual patient chart access
- [ ] Confirm all active staff have individual accounts (no shared logins)

## Storage & infrastructure

- [ ] Note storage usage from health check (backups + documents MB)
- [ ] Confirm server room / cabinet locked; no new port forwarding to internet
- [ ] Workstations lock when unattended (clinic policy spot-check)

## Documentation

- [ ] Emergency contacts current in Help center
- [ ] New staff received badge and PIN change walkthrough
- [ ] Completed checklist signed and dated below
