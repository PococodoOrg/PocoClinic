### After every restore

- [ ] Admin can sign in  
- [ ] Patient list loads; count looks reasonable  
- [ ] Opened at least one note and one document  
- [ ] Staff badge test (reissue if backup was old)  
- [ ] Fresh backup taken  
- [ ] Vault **document encryption key** available if documents would not open
