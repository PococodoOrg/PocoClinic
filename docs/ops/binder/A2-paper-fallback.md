# A2 — Paper care when EMR is down

**Ops binder · Section A (Emergency)** · Use only while PocoClinic is unavailable.

## Priority

1. **Patient safety and care continue** on paper  
2. Keep paper notes **organized by patient name + date of birth**  
3. When the system returns, an administrator enters or attaches records per clinic policy  

## What to capture (minimum)

For each patient seen while the system is down, write:

| Field | Write here / on clinic paper forms |
|-------|-------------------------------------|
| Full name | |
| Date of birth | |
| Date / time of visit | |
| Reason for visit / chief complaint | |
| Clinical notes (who wrote them) | |
| Forms signed (list titles) | |
| Documents received (referrals, imaging) — store in folder | |

Use your clinic’s existing paper intake / SOAP / consent pads if you have them. This page is the **reminder**, not a replacement for licensed clinical forms.

## Front desk checklist (outage)

- [ ] Tell staff: EMR down — use paper; do not invent workarounds on personal phones  
- [ ] Note **outage start time** on [Incident & restore log](./A3-incident-restore-log.md)  
- [ ] Collect paper charts in one tray labeled **PocoClinic outage — [date]**  
- [ ] Do **not** register “temporary” patients in a random spreadsheet unless clinic policy says so  
- [ ] When EMR returns: admin restores or catches up; tick the incident log  

## Do not

- Email or text PHI to personal accounts to “get through the day”  
- Share one staff login “just this once” when the system returns  
- Throw away paper from the outage day before catch-up is confirmed  

## After the system is back

1. Administrator confirms server healthy (Section A1 / dashboard)  
2. Enter or scan paper into the correct patient charts  
3. Shred or file paper per clinic retention policy  
4. Complete the incident log row
